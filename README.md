# HanhTrinhNgocRong

Game web RPG 2D phong cách Ngọc Rồng Online - fan game phi thương mại chạy offline.

## Công nghệ
- TypeScript + Vite + Canvas 2D
- Pixel art procedural bằng code, không dùng asset ngoài
- Âm thanh WebAudio (sẽ làm ở giai đoạn 10)

## Chạy
```bash
npm install
npm run dev
```
